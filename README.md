# WordMarkdownMacro

ماكرو لبرنامج Microsoft Word يحوّل النص المكتوب بصيغة Markdown والملصوق داخل المستند إلى تنسيقات حقيقية في برنامج Word:
عناوين، وغامق، ومائل، وقوائم، واقتباسات، ومقاطع كود، وروابط، وجداول، وحواشٍ سفلية. مصمَّم للنصوص العربية
(من اليمين إلى اليسار)، ويعمل على نظامي Windows وmacOS.

## الملفات

- `MarkdownToWord.bas`: كود الماكرو كاملًا (وحدة واحدة بلغة VBA).
- `test-sample.md`: نص تجريبي يغطي كل ما يدعمه الماكرو.

## التثبيت

يُثبَّت الماكرو في القالب العام لبرنامج Word (قالب Normal)، فيصبح متاحًا في كل المستندات.

1. نزّل الملف `MarkdownToWord.bas` بإحدى طريقتين:
   - **الملف وحده:** من [الرابط المباشر](https://github.com/aammsh/WordMarkdownMacro/raw/main/MarkdownToWord.bas)،
     أو افتح الملف في المستودع واضغط زر التنزيل (السهم للأسفل) بجانب الزر Raw.
   - **المشروع كاملًا:** في صفحة المستودع اضغط الزر الأخضر **Code** ← الأمر **Download ZIP**، ثم فُكّ ضغط الملف.
2. افتح برنامج Word، ثم افتح محرر Visual Basic:
   - **نظام Windows:** اضغط الاختصار `Alt + F11`، أو من تبويب **المطور (Developer)** اختر زر **Visual Basic**.
   - **نظام macOS:** من قائمة **أدوات (Tools)** ← **ماكرو (Macro)** ← **محرر Visual Basic (Visual Basic Editor)**.
3. في القائمة اليسرى المسمّاة Project انقر بالزر الأيمن على القالب **Normal**، ثم اختر الأمر **Import File…**
   (وفي نظام macOS يمكن أيضًا: قائمة **File** ← الأمر **Import File…** بعد تحديد القالب Normal).
4. اختر الملف `MarkdownToWord.bas`. ستظهر وحدة باسم `MdToWordModule` داخل القالب `Normal` في مجلد `Modules`.
5. احفظ بالاختصار `Ctrl + S` (وفي نظام macOS `Cmd + S`)، ثم أغلق المحرر.

> واجهة محرر Visual Basic بالإنجليزية دائمًا، حتى في النسخة العربية من برنامج Word.

### التحديث إلى إصدار أحدث

احذف الوحدة القديمة أولًا، ثم ثبّت الجديدة:

1. في محرر Visual Basic افتح القالب **Normal** ثم مجلد **Modules**.
2. انقر بالزر الأيمن على الوحدة القديمة ← الأمر **Remove …** ← الزر **No** عند السؤال عن تصديرها.
3. اتبع خطوات التثبيت أعلاه من الخطوة 3.

## الاستعمال

1. الصق النص المكتوب بصيغة Markdown في مستند Word (يُفضَّل مستند جديد أو نسخة من المستند).
2. افتح قائمة وحدات الماكرو:
   - **نظام Windows:** الاختصار `Alt + F8`، أو تبويب **عرض (View)** ← **وحدات الماكرو (Macros)**.
   - **نظام macOS:** قائمة **أدوات (Tools)** ← **ماكرو (Macro)** ← **وحدات الماكرو (Macros)**.
3. اختر الماكرو `MarkdownToWord` ثم زر **تشغيل (Run)**.

يعمل الماكرو على المستند المفتوح كاملًا، ولا يعتمد على مكان المؤشر. ويُسجَّل التحويل كله
خطوة تراجع واحدة، فالضغط على الاختصار `Ctrl + Z` مرة واحدة يعيد المستند كما كان.

### اختصار لوحة مفاتيح (اختياري، لنظام Windows)

**ملف (File)** ← **خيارات (Options)** ← **تخصيص الشريط (Customize Ribbon)** ←
زر **تخصيص… (Customize…)** بجانب **اختصارات لوحة المفاتيح (Keyboard shortcuts)** ←
من **الفئات (Categories)** اختر **وحدات الماكرو (Macros)** ← اختر الماكرو `MarkdownToWord` ←
اضغط الاختصار المطلوب ← **تعيين (Assign)**.

## ما الذي يحوّله

| صيغة Markdown | النتيجة في برنامج Word |
|---|---|
| `# …` حتى `###### …` | أنماط العناوين المدمجة من 1 إلى 6 |
| `**نص**` أو `__نص__` | غامق |
| `*نص*` | مائل |
| `***نص***` | غامق ومائل |
| `~~نص~~` | نص مشطوب |
| `` `كود` `` | خط ثابت العرض |
| ` ``` ` … ` ``` ` | مقطع كود بخلفية رمادية، لا تُطبَّق عليه بقية التحويلات |
| `- عنصر` أو `* عنصر` أو `+ عنصر` | قائمة نقطية (مع التداخل) |
| `1. عنصر` أو `1) عنصر` | قائمة مرقّمة (مع التداخل) |
| `- [ ]` و `- [x]` | ☐ و ☑ |
| `> اقتباس` | مسافة بادئة ومائل وخط جانبي |
| `---` أو `***` أو `___` | خط فاصل أفقي |
| `[نص](رابط)` | ارتباط تشعبي |
| `![وصف](رابط)` | ارتباط تشعبي نصي (لا تُدرج الصورة) |
| `\*` و `\_` و `\|` | تُعرض كما هي |
| جدول بصيغة `\|…\|…\|` | جدول حقيقي في برنامج Word |
| `[^1]` مع سطر `[^1]: نص الحاشية` | حاشية سفلية حقيقية في برنامج Word |

### الجداول

```
| العمود الأول | العمود الثاني | العمود الثالث |
|:------------|:------------:|-------------:|
| قيمة        | قيمة          | ١٢٣          |
```

- سطر الفاصل `|---|` مطلوب، وهو ما يميّز الجدول عن نص عادي فيه شرطات عمودية.
- المحاذاة تُقرأ من النقطتين: `:---` يسار، و`:---:` وسط، و`---:` يمين.
- صف العناوين غامق، ويتكرر تلقائيًا إذا امتد الجدول على أكثر من صفحة.
- يُبنى الجدول من اليمين إلى اليسار بعرض الصفحة كاملًا.
- الخلايا الناقصة تُملأ فارغة.
- `<br>` داخل خلية تصبح سطرًا جديدًا في الخلية نفسها.

### الحواشي

```
قال المؤلف كذا[^1]، ونقله غيره[^المصدر].

[^1]: نص الحاشية الأولى، ويمكن أن يكون فيه **غامق** و[رابط](https://example.com).
[^المصدر]: نص الحاشية الثانية.
```

- تتحول كل إشارة `[^…]` إلى حاشية سفلية حقيقية، ويرقّمها برنامج Word تلقائيًا بحسب ترتيب ظهورها، لا بحسب الرقم المكتوب.
- يُنقل نص التعريف إلى الحاشية بتنسيقه (الغامق والمائل والروابط)، ثم يُحذف سطر التعريف من المتن.
- يمكن أن يكون اسم الحاشية رقمًا أو كلمة بلا مسافات، ولا يفرّق بين الحروف الكبيرة والصغيرة.
- التعريف الذي لا تشير إليه أي إشارة يبقى في مكانه نصًا عاديًا، فلا يضيع نصه.
- الإشارة التي ليس لها تعريف تبقى نصًا كما هي.
- يوضع رقم الحاشية بين قوسين `(1)` في المتن وفي أسفل الصفحة، ويكون الرقم في أسفل الصفحة بمستوى النص وبنمط نص الحاشية، لا مرتفعًا. وإذا وجد الماكرو حواشي في النص سألك عند التشغيل: هل تريد الأرقام بين قوسين؟ ويمكن إلغاء جعل الرقم بمستوى النص من الإعداد `FOOTNOTE_NUMBER_AS_TEXT`.
- القوسان نص عادي بجانب الرقم التلقائي، فيبقى الترقيم تلقائيًا. أما الحاشية التي تُضاف يدويًا بعد التحويل فلا يُضاف إليها القوسان.

## الإعدادات

في أعلى الوحدة، قبل أول إجراء `Sub`:

| الإعداد | الافتراضي | معناه |
|---|---|---|
| `RTL_DOC` | `True` | مستند من اليمين إلى اليسار |
| `TABLE_STYLE` | `""` | اسم نمط جدول بحروف لاتينية؛ إن تُرك فارغًا يُستعمل نمط شبكي مدمج، وإلا فحدود بسيطة |
| `CODE_FONT` | `"Consolas"` | خط الكود للنص اللاتيني |
| `CODE_FONT_BI` | `"Courier New"` | خط الكود للنص العربي (يجب أن يدعم العربية) |
| `REMOVE_EMPTY_LINES` | `True` | حذف الأسطر الفارغة الزائدة |
| `CONVERT_LINE_BREAKS` | `True` | تحويل فواصل الأسطر اليدوية إلى فقرات |
| `HONOR_TWO_SPACE_BREAK` | `False` | معاملة مسافتين في نهاية السطر فاصلَ سطر |
| `FOOTNOTE_PARENS_ASK` | `True` | سؤال المستخدم عند التشغيل عن القوسين إذا وُجدت حواشي؛ `False` لاستعمال الإعداد التالي دون سؤال |
| `FOOTNOTE_PARENS` | `True` | الجواب الافتراضي في السؤال، أو القرار نفسه إذا أُلغي السؤال: `True` للقوسين `(1)`، و`False` للرقم وحده |
| `FOOTNOTE_NUMBER_AS_TEXT` | `True` | رقم الحاشية في أسفل الصفحة بمستوى النص وبنمط نص الحاشية؛ `False` ليبقى مرتفعًا كعادة Word |

> لا تكتب حروفًا عربية داخل الكود في محرر Visual Basic؛ قد تتحول إلى `?`.
> النصوص العربية التي يحتاجها الماكرو تُبنى من أكواد ترميز Unicode عبر الدالة `U()`.

## القيود المعروفة

- الصور لا تُدرج؛ `![وصف](رابط)` تصبح رابطًا نصيًا.
- مقاطع الكود المكتوبة بأربع مسافات بادئة (بدل ` ``` `) لا تُعامل كودًا.
- الجداول المتداخلة وقوائم التعريف غير مدعومة.
- تعريف الحاشية فقرة واحدة؛ الأسطر التالية له المزاحة بمسافات لا تُضم إليه.
- إذا تكررت الإشارة نفسها في أكثر من موضع، أُنشئت لكل موضع حاشية مستقلة بالنص نفسه.
- الإشارة إلى حاشية من داخل حاشية أخرى تبقى نصًا، لأن برنامج Word لا يدعم الحواشي المتداخلة.
- أقصى عمق لتداخل القوائم خمسة مستويات.
- المائل داخل الغامق (`**نص *مائل* داخله**`) لا يُحوَّل بشكل صحيح.
- جدولان متلاصقان دون سطر فارغ بينهما يُعامَلان جدولًا واحدًا.
- يعالج الماكرو متن المستند فقط، لا الرؤوس والتذييلات ومربعات النص.
